# Güvenlik Politikası

## Desteklenen Sürümler

Bu bölümü, projenizin hangi sürümlerinin hâlihazırda güvenlik güncellemeleriyle desteklendiğini belirtmek için kullanın.

| Sürüm | Destekleniyor      |
| ----- | ------------------ |
| 5.1.x | :white_check_mark: |
| 5.0.x | :x:                |
| 4.0.x | :white_check_mark: |
| < 4.0 | :x:                |

## Güvenlik Açığı Bildirme

Bu bölümü, kullanıcılara bir güvenlik açığını nasıl bildirebileceklerini açıklamak için kullanın.

Bildirimi nereye yapmaları gerektiğini, bildirilen bir güvenlik açığıyla ilgili ne sıklıkla güncelleme alabileceklerini, güvenlik açığı kabul edildiğinde veya reddedildiğinde neler olacağını vb. bilgileri paylaşın.
